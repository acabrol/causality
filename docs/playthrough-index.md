# Playthrough Simulations

This file is the English index of playthrough simulations.

The official playable walkthroughs are maintained in the scenarios, because they must strictly use the current **Causality** rules:

- [Glass Fever Protocol](./scenarios/glass-fever-protocol-gm-prep.md): recommended starter scenario. It contains a starter mode and a complete mode.
- [Ashfall Battalion](./scenarios/ashfall-battalion-gm-prep.md)
- [The Clockmaker's Child](./scenarios/clockmakers-child-gm-prep.md)
- [The Iron Witness](./scenarios/iron-witness-gm-prep.md)
- [Public Record Trap](./scenarios/public-record-trap-gm-prep.md)

Each scenario walkthrough uses `scripts/simulate_dice_rolls.py`, applies the current **Rewind Dice** formula, and recalculates game statistics at the end of the scenario.
