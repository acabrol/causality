# Ashfall Battalion - Game Master Prep

This original **Causality** case presents a tactical investigation around a hostile battlefield Counter-System.

## Scenario Premise

The Ashen Host is crossing the Black Salt Coast through autonomous ash bodies called Cinders. Coalition command believes **Operation Lanternfall** will retake the shore. It is a trap.

Alice is assigned to Ashfall Battalion as a civilian liaison and becomes linked to an enemy **Counter-System** after destroying an Ember Node during the failed landing. Each death reopens the same deployment-morning **Branched Timeline** until a medical sync procedure severs the link. The true command source, the **Rootmind**, is not at the false northern beacon. It is buried under the Flooded Relay.

## Core Game Master Truth

- Operation Lanternfall is an ambush.
- Ember Nodes report failed outcomes to the Rootmind.
- Alice's link is useful but dangerous; each remembered death creates Willpower pressure.
- The northern beacon is false.
- The Flooded Relay is the real Rootmind location.
- Once the sync procedure severs Alice's link, there is no automatic reset.
- Destroying the Rootmind can create a coherent victory Now if the Node-link cause is preserved.

## Special Rule: Node-Link Loop

- Before sync surgery, Alice's death reopens deployment morning.
- Do not replay every death. Each montage loop may reveal one Evidence, Condition, route, or conflict.
- Every three remembered deaths add a temporary `-5` Willpower penalty until the next clean merge.
- After sync surgery, death is final unless a scenario-specific merge explains survival.
