# Rewind Dice Abacus

Use these pages during play to read **Rewind Percentage** outcomes without recalculating them at the table.

Each page covers every possible die result for every rewind distance from 1 to 20 **Time Units**.

**Formula:** `r = (Rewind Die result / rewind distance) x 100`

**Cell format:** `percentage<br>outcome`
