# Temporal Effect Ideas

This catalog turns common and rare temporal story mechanics into **Causality** design prompts. It is not a rules expansion by itself: each row states how naturally the effect fits the current rules and what the Game Master must prepare if they use it.

Compatibility scale:

- **Total:** works with the current rules using `Main Timeline`, `Branched Timeline`, `Fact`, `Condition`, `Evidence`, `Merge`, `Willpower`, `Rewind Dice`, or `Time Offender` tools.
- **Partial:** works as a scenario technique, but needs limits, a ruling, or a narrow interpretation.
- **Low / module needed:** not native to the current game; use only as a special anomaly, scenario premise, or future optional module.
