# Language Support

The main language of this repository is **English**.

All primary documentation at the repository root and in `docs/` must be written in English. Translations and original non-English material live under `i18n/`.

Currently supported languages:

| Language | Path | Status |
|---|---|---|
| English | `/README.md`, `/docs/` | Primary |
| French | `/i18n/fr/` | Original source and translation area |

## Policy

- Keep English documentation as the canonical public version.
- Keep French material under `i18n/fr/`.
- When adding a new major English document, add a matching French translation only under `i18n/fr/` when it is ready.
- Do not mix languages in root-level documents.
