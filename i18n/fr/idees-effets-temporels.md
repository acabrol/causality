# Idees d'effets temporels

Ce catalogue transforme les mecaniques narratives temporelles en pistes de conception pour **Causality**. Ce n'est pas une extension de regles complete : chaque ligne indique si l'effet fonctionne naturellement avec les regles actuelles et ce que le **MJ** doit preparer pour l'utiliser.

Echelle de compatibilite :

- **Totale** : fonctionne avec les regles actuelles via `Main Timeline`, `Branched Timeline`, `Fact`, `Condition`, `Evidence`, `Merge`, `Volonte`, `Rewind Dice` ou `Time Offender`.
- **Partielle** : fonctionne comme technique de scenario, mais demande une limite, une decision du MJ ou une interpretation restreinte.
- **Faible / module requis** : pas natif dans le jeu actuel ; a utiliser comme anomalie speciale, premise de scenario ou futur module optionnel.
