# Abaques Rewind Dice

Utilisez ces pages pendant le jeu pour lire les resultats de **Rewind Percentage** sans refaire les calculs a la table.

Chaque page couvre tous les resultats possibles du de pour chaque distance de rewind de 1 a 20 **Time Units**.

**Formule:** `r = (Rewind Die result / rewind distance) x 100`

**Format de cellule:** `pourcentage<br>effet`
