# Causality

[English version](../../README.md)

**Causality est un jeu de rôle coopératif d’enquête causale pour 2 à 5 joueurs et un maître de jeu.**

Dans cet univers, **le temps n’existe pas** : nous percevons l’enchaînement cohérent des causalités, chaque événement étant la conséquence des précédents. Cet enchaînement peut être déroulé à l’inverse, à l’image d’un écoulement réversible dans un fluide visqueux.

Les joueurs incarnent des enquêteurs causaux, les **Investigators**, utilisant **le System**. Ce dispositif scientifique complexe associe un ordinateur quantique aux propriétés de masse et d’énergie d’un micro-trou noir. Dans la fiction, il résulte de recherches ayant unifié la mécanique quantique et l’espace-temps en substituant à la composante temporelle le **théorème de causalité générale**.

Le System ouvre la **Causality Gate**, centrée sur la **Main Timeline**. Les enquêteurs réexécutent les causes passées dans des **Branch**, aussi appelées **Branched Timelines**, y agissent puis tentent un **Merge** sur la Main Timeline pour revenir dans le **Now**. Le **Time Flow** désigne la structure causale accessible par la Gate.

Les **Rewind Dice représentent des capsules d’énergie noire** consommées pour utiliser le System. Chaque intervention doit préserver un présent cohérent : modifier une cause peut détruire une preuve ou effacer les conditions d’existence des enquêteurs. Les Branch vécues mais non intégrées alourdissent leur charge cognitive, mesurée par la **Charge mentale**, et peuvent les faire sombrer dans la folie.

Le [socle d’univers et du System](./univers-et-system.md) détaille ce fonctionnement et sa référence visuelle, la démonstration d’une cellule de Couette.

## Ce qui le distingue

- **Pas de voyage temporel physique :** le passe n'est pas un lieu. Le present est le resultat observable des causes passees.
- **Enquete causale :** les joueurs reconstruisent des chaines cachees de Facts, Conditions et Evidence.
- **Realites de Branched Timeline :** les Investigators ouvrent des Branched Timelines temporaires pour tester d'autres actions.
- **Conflits de Merge :** les Branched Timelines doivent etre integrees dans la Main Timeline sans casser les Facts essentiels.
- **Carte de Time Flow :** la Main Timeline et toutes les Branched Timelines forment le Time Flow jusqu'au Now.
- **Pression psychologique :** les Branched Timelines non Merged laissent des souvenirs de realites qui n'existent plus.
- **Regles simples a echelle humaine :** les Investigators commencent avec 0 de Charge mentale et 10 Health.
- **Combat rapide :** les attaques touchent automatiquement ; seuls les des de degats sont lances.
- **Des classiques a la table :** chaque Investigator recoit un set classique de des D&D.
- **Rewind Dice comme energie limitee :** d4, d6, d8, d10, d12 et d20 servent a rembobiner la causality vers une Time Unit dans un Time Flow de 20 unites.
- **Rewind Percentage base sur la distance :** le meme de est plus sur pour un rewind court et plus risque pour un rewind profond.

## Idee centrale

Le jeu commence au Now : l'etat present observable de l'univers, produit par la causality passee. Le Game Master prepare une structure causale cachee : Facts, Conditions, dependencies et Evidence. Les joueurs recoivent des indices initiaux, placent les Facts confirmes sur la Main Timeline partagee, puis utilisent les Rewind Dice pour ouvrir des Branched Timelines sur les Time Units anterieures du Time Flow.

Quand une Branched Timeline est prete, le groupe tente un **Merge**. La Branched Timeline est Merged sur le Now : le System rejoue la causality depuis la Time Unit de depart jusqu'au present et verifie si la Main Timeline resultante reste coherente. Les Minor Conflicts sont resolus par choix joueur et jets d'action au pourcentage reduits par la Charge mentale. Les Major Conflicts demandent une nouvelle action causale ou des Branched Timelines correctives.

La partie se termine quand les Investigators resolvent le mystere, quand le System n'a plus d'energie, ou quand la Main Timeline finale ne preserve plus le Now originel.

## Termes cles

Les termes de jeu centraux restent en anglais dans toutes les langues :

| Terme | Sens |
|---|---|
| Main Timeline | Etat partage et actuellement observable du monde. |
| Causality Gate | Ouverture créée par le System, centrée sur la Main Timeline, donnant accès au Time Flow. |
| Branch | Nom court d’une Branched Timeline, réalité alternative dans laquelle les enquêteurs agissent. |
| Branched Timeline | Execution causale alternative temporaire creee par un Investigator. |
| Time Flow | Structure temporelle ouverte composee de la Main Timeline et de toutes les Branched Timelines jusqu'au Now. |
| Now | Etat present observable de l'univers, produit par la causality passee. |
| Time Unit | Une des 20 unites numerotees et Atomic du Time Flow. |
| Atomic | Propriete de regle indiquant qu'une Time Unit ne peut pas etre divisee ni rejointe par une sous-periode. |
| System | Dispositif associant ordinateur quantique et micro-trou noir, qui ouvre la Causality Gate et donne accès au Time Flow. |
| Counter-System | System utilise par un Time Offender. Il fonctionne comme le System des Investigators, mais son nom distingue l'activite adverse a la table. |
| Investigators | Personnages joueurs qui utilisent le System. |
| Time Offender | PNJ controle par le Game Master avec un ou plusieurs objectifs opposes aux joueurs. |
| Rewind Dice | Six dés représentant les capsules d’énergie noire dépensées pour ouvrir des Branch : d4, d6, d8, d10, d12 et d20. |
| Rewind Percentage | Score d'ouverture calcule avec `resultat du Rewind Die / distance de rewind x 100`. |
| Branched | Action d'ouvrir une Branched Timeline sur une Time Unit. |
| Merged | Action de resoudre une Branched Timeline dans le Now. |

## Inspiration

Causality est inspire de [Continuum: Roleplaying in the Yet](http://www.aetherco.com/continuum/), le jeu de role temporel publie par Aetherco/Dreamcatcher. Causality garde la fascination pour les consequences temporelles rigoureuses, la pression du paradoxe et la coherence de la realite, mais deplace le principe vers le rejeu causal plutot que le voyage physique dans le temps.

## Boucle principale

```text
1. Etudier l'Evidence et la Main Timeline.
2. Choisir un objectif d'enquete.
3. Choisir une Time Unit a explorer.
4. Depenser un Rewind Die pour ouvrir une Branched Timeline.
5. Agir dans la Branched Timeline.
6. Creer, supprimer ou modifier des Facts.
7. Tenter un Merge.
8. Resoudre les conflits.
9. Mettre a jour la Main Timeline.
10. Recalculer la Charge mentale du joueur actif a la fin de son tour.
11. Continuer jusqu'a resolution du mystere ou epuisement de l'energie du System.
```
