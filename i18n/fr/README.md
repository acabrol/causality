# Causality - Version francaise

Ce dossier contient les documents francais du projet **Causality**.

La langue principale du depot GitHub est l'anglais. Les documents principaux se trouvent a la racine du depot et dans `docs/`. Les versions francaises sont conservees ici pour permettre un support multilingue clair sans melanger les langues dans les documents principaux.

**Inspiration :** Causality est inspire de [Continuum: Roleplaying in the Yet](http://www.aetherco.com/continuum/), le jeu de role temporel publie par Aetherco/Dreamcatcher.

## Documents

- [Document de conception original](./causalite-jeu-de-role.md)

## Politique de langue

- Anglais: version principale du projet.
- Francais: version traduite ou source conservee dans `i18n/fr/`.
- Pour le moment, seules les langues anglaise et francaise sont supportees.
